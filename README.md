# Word World

## 概要

**Word World** は、他大学のサークルとのコラボ個展で制作したインタラクティブアート作品です。

漢字パネルを台座にはめ込むことで、投影された映像内にその文字に応じた変化が現れます。  
来場者が文字を「読む」だけでなく、実際に手で選び、映像世界へ反映させる体験を目指しました。

## 制作情報

- 制作時期：大学2年生 2〜3月
- 作品種別：インタラクティブアート
- 使用技術：Unity / Blender / GitHub
- 担当：デザイン / メインプログラマー

## 工夫した点

この制作では、チーム内にプログラマーが複数人いたため、各パネルに対応する演出を効率よく追加できるように、共通処理をテンプレート化しました。

私が基本となるプログラム構成を作成し、他のメンバーが各パネルに対応した要素を追加できる形にすることで、分担しながら制作を進めやすい環境を整えました。

また、初めてGitHubを使用し、共同制作におけるバージョン管理や作業共有にも取り組みました。
