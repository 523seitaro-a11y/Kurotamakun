# Word World

他大学のサークルとのコラボ個展用に制作した、漢字パネルと映像演出が連動するインタラクティブアート作品です。

## 作品概要

くろたま君が、漢字で表現された世界を進む映像を投影し、鑑賞者が漢字パネルを台座にはめ込むことで、その文字に応じた変化が映像内に現れる体験を制作しました。

例えば、「掘」のパネルをはめるとキャラクターがドリルに変身して地中へ潜り、「宙」のパネルをはめるとロケットに変身して宇宙まで飛んでいくなど、漢字の意味と映像演出が連動する構成にしています。

パネルの読み込みにはNFCタグを利用しました。各パネルにNFCタグを貼り、台座に設置したNFCリーダーから情報を読み取ることで、はめ込まれた漢字パネルに応じた演出をUnity上で切り替える仕組みを実装しています。

来場者が文字を「読む」だけでなく、実際に手で選び、映像世界へ反映させる体験を目指しました。

## 使用技術

- Unity 6000.1.0f1
- C#
- Universal Render Pipeline
- Unity Input System
- Unity 2D Animation / 2D PSD Importer
- NFCタグ / NFCリーダー
- PC/SCライブラリ

## 実装の工夫

作品全体の構成が崩れないように共通処理をフォーマット化しました。

基本となるプログラム構成を用意し、メンバーが各パネルに対応する演出や要素を追加できる形にしたことで、複数人で分担しながら効率よく制作を進められるようにしています。

また、NFCタグから読み取った値をUnity側の状態管理に反映し、その状態に応じてキャラクターや背景、演出オブジェクトを切り替えることで、物理的なパネル操作と映像内の変化が直感的につながる体験を目指しました。

## 実行方法

1. このリポジトリをクローンします。
2. Unity Hubから `WordGame` フォルダをプロジェクトとして開きます。
3. Unity 6000.1.0f1、または互換性のあるUnity 6系のエディタで開きます。
4. `Assets/Scenes/SampleScene.unity` または `Assets/Scenes/SmallWorld.unity` を開きます。
5. NFCリーダーをPCに接続し、PC/SC経由で読み取れる状態にします。
6. Unityエディタ上で再生し、NFCタグ付きの漢字パネルをリーダーに近づけると、対応する演出が切り替わります。
